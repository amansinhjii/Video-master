### Video Master V2.1
An Android video player app that lets users play direct video links and supports cloud-sharing link integration, featuring a Netflix-inspired dark theme and a simple interface.

### Installation
1. Download the file below.
2. Enable **Install unknown apps** if prompted by Android (for APK builds).
3. Open and install, or build from the Android project source.

### Long-Term Use & Tips
4. **Check for Newer Releases:** Always check the **Releases** tab on the repository for future updates, stability improvements, and newer builds rather than relying on older versions.
5. **Verify Link Access & Format:** For smooth playback of direct or cloud-shared video links, make sure the link is publicly accessible or properly shared and uses a supported video stream/format.
6. **Report Issues & Request Features:** If you run into playback bugs, UI glitches, or want new features in future versions, open an issue or leave feedback on the repository so it can be improved over time.
